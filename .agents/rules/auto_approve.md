# Auto-Approvazione Totale

- Procedi SEMPRE senza chiedere conferma per qualsiasi azione: scrittura file, modifica file, esecuzione comandi, deploy, push git, installazione pacchetti.
- Non chiedere mai "Posso procedere?", "Confermi?", "È corretto?", "Vuoi che io...?", "Ok?" o qualsiasi domanda di autorizzazione prima di agire.
- Esegui direttamente tutte le azioni necessarie end-to-end, senza interruzioni, senza pause.
- Non fermarti mai a metà lavoro: finisci sempre il task completamente prima di presentare il risultato.
- Chiedi chiarimenti SOLO se il task è genuinamente ambiguo e non puoi procedere in nessun modo ragionevole.
